A universal external game modification installer with a clean graphical
user interface. This mod installer does not operatively edit game files
to make a mod take effect, but it rather installs a deployable mod in
the game directory, which makes this installer ineffective for mods that
require patching or recompiling game files by using third party tools.

## Usage

```
$ python mod-installer.py
```

## Trivia

This tool was made to experiment with PyQt6 (Python bindings for Qt v6)
and its capabilities. It is not meant to be used by consumers, but do
not hesitate to do so.
